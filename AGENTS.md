# Инструкции для ИИ-агентов

Монорепозиторий Trenly: `docs/` — документация, `openspec/` — спецификации, `backend/` — Django (API, админка на Django Admin), `frontend/` — Vue 3 (кабинет тренера), `tg_bot/` — aiogram 3 (чат клиента, [ADR 0006](docs/architecture/adr/0006-telegram-bot-aiogram.md)).

- Документация пишется на русском языке.
- Перед работой со спецификациями прочитай [`docs/spec-driven-process.md`](docs/spec-driven-process.md) и [`docs/glossary.md`](docs/glossary.md).
- Используй термины из глоссария, а в коде — имена из колонки «В коде»; новый термин сначала добавь в глоссарий.
- Функциональные требования оформляются только как спецификации OpenSpec в `openspec/`, не отдельными документами в `docs/`.
- Каждое требование в спецификации ссылается на бизнес-требование `BR-xxx` из `docs/business/requirements.md`.
- Если реализация требует изменить поведение для пользователя, сначала обнови спецификацию, а не меняй поведение молча.
- Изменение архитектуры сопровождается правкой соответствующего уровня в `docs/architecture/c4/` и новым ADR в `docs/architecture/adr/`.
- Новые документы создавай по шаблонам из `templates/`.
