# Инструкции для ИИ-агентов

## Репозиторий

Монорепозиторий Trenly:

- `docs/` — документация.
- `openspec/` — спецификации.
- `backend/` — Django (API, админка на Django Admin).
- `frontend/` — Vue 3 (кабинет тренера).
- `tg_bot/` — aiogram 3 и aiogram_dialog.

В `backend/` домен — приложение Django со слоями `api`, `dto`, `services`, `entities`, `repositories`, `models`. При
изменении бэкенда следуй [`backend/AGENTS.md`](backend/AGENTS.md).

## Язык и термины

- Документация пишется на русском языке.
- У модуля, класса и функции Python есть docstring: короткий и понятный, на русском языке.
- Используй термины из глоссария, а в коде — имена из поля «В коде»; новый термин сначала добавь в глоссарий.

## Спецификации

- Перед работой со спецификациями прочитай [`docs/spec-driven-process.md`](docs/spec-driven-process.md) и
  [`docs/glossary.md`](docs/glossary.md).
- Функциональные требования оформляются только как спецификации OpenSpec в `openspec/`, не отдельными документами в
  `docs/`.
- Каждое требование в спецификации ссылается на бизнес-требование `BR-xxx` из `docs/business/requirements.md`. Номера
  идут подряд. В текущий роадмап входят BR-001–BR-006.
- Если реализация требует изменить поведение для пользователя, сначала обнови спецификацию, а не меняй поведение молча.

## Архитектура и данные

- Изменение архитектуры сопровождается правкой соответствующего уровня в `docs/architecture/c4/` и новым ADR в
  `docs/architecture/adr/`.
- Модель данных PostgreSQL ведётся отдельно в [`docs/architecture/data-model.md`](docs/architecture/data-model.md):
  диаграмма Mermaid `erDiagram`. Любое изменение постоянных моделей, полей или связей обновляет этот файл в том же
  изменении. Имена сущностей берутся из глоссария, поле «В коде».

## Интерфейс

- UI-дизайн кабинета тренера и Mini App ведётся в Figma через Figma AI. Новый или заметно изменённый экран 
- сначала появляется редактируемым макетом в файле Figma, затем во `frontend/`.

## Документы и оформление

- Новые документы создавай по шаблонам из `templates/`.
- Длина строки в любых файлах — 120 символов. Python форматирует Ruff (`ruff.toml`), остальные текстовые файлы —
  Prettier (`.prettierrc.json`). Lock-файлы не переносить.
