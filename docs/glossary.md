# Глоссарий

Единый словарь терминов для документации, спецификаций и кода. Поле «В коде» фиксирует англоязычное имя, чтобы оно
совпадало в документации, бэкенде и фронтенде.

- **Термин:** Тренер. **В коде:** `Trainer`. **Определение:** Персональный фитнес-тренер; работает в веб-кабинете. На
  текущем роадмапе учётку заводит администратор.
- **Термин:** Клиент. **В коде:** `Client`. **Определение:** Подопечный тренера; бесплатно работает в боте и в Mini App.
  Подключён ровно к одному тренеру.
- **Термин:** Администратор. **В коде:** `Admin`. **Определение:** Сотрудник Trenly; управляет тренерами в админке.
- **Термин:** Админка. **В коде:** `AdminPanel`. **Определение:** Интерфейс администратора на Django Admin.
- **Термин:** Подписка. **В коде:** `Subscription`. **Определение:** Ежемесячная оплата тренером доступа к Trenly. Без
  активной подписки клиенты тренера могут только просматривать свои статусы и графики.
- **Термин:** Пробный период. **В коде:** `Trial`. **Определение:** Бесплатный период после регистрации тренера со всеми
  функциями.
- **Термин:** Кабинет тренера. **В коде:** `TrainerDashboard`. **Определение:** Веб-приложение тренера в браузере.
- **Термин:** Токен доступа. **В коде:** `AccessToken`. **Определение:** JWT, которым тренер вызывает API кабинета.
  Живёт 15 минут. Передаётся в заголовке `Authorization: Bearer`.
- **Термин:** Токен обновления. **В коде:** `RefreshToken`. **Определение:** Секрет, которым тренер получает новую пару
  токенов без повторного пароля. Живёт 14 дней. Сам кабинет не открывает. После выдачи новой пары предыдущий секрет не
  действует.
- **Термин:** Mini App. **В коде:** `ClientMiniApp`. **Определение:** Веб-приложение клиента внутри Telegram: дневник и
  итог КБЖУ за день, ручной ввод КБЖУ на приём пищи, тренировки по дням, статистика посещённых тренировок.
- **Термин:** Бот. **В коде:** `TelegramBot`. **Определение:** Telegram-бот Trenly: чат клиента. Подключение, анкета,
  фото еды, согласие на занятие за день до него.
- **Термин:** Подключение. **В коде:** `ClientInvite`. **Определение:** Ссылка, которой тренер открывает клиенту бота.
- **Термин:** Анкета. **В коде:** `Questionnaire`. **Определение:** Данные, которые клиент называет в диалоге бота: имя,
  фамилия, рост, вес, цель. В конце он подтверждает тренера и сохраняет анкету.
- **Термин:** Цель. **В коде:** `Goal`. **Определение:** Чего добивается клиент: похудение, набор мышечной массы и т. п.
- **Термин:** Дневник питания. **В коде:** `NutritionDiary`. **Определение:** Записи о приёмах пищи клиента с КБЖУ.
- **Термин:** КБЖУ. **В коде:** `Macros`. **Определение:** Калории, белки, жиры, углеводы.
- **Термин:** Рекомендация. **В коде:** `NutritionRecommendation`. **Определение:** Ежедневный совет клиенту по питанию
  с учётом цели.
- **Термин:** Тренировка. **В коде:** `Workout`. **Определение:** Занятие, которое тренер записывает клиенту.
- **Термин:** Отметка посещения. **В коде:** `Attendance`. **Определение:** Ответ клиента за день до занятия, которое
  записал тренер: придёт или нет.
- **Термин:** Награда. **В коде:** `Reward`. **Определение:** Достижение клиента за регулярность.
- **Термин:** Журнал. **В коде:** `Journal`. **Определение:** Автоматическая хронология питания, тренировок и посещений
  клиента.
- **Термин:** Отчёт. **В коде:** `ProgressReport`. **Определение:** Сводка прогресса клиента за период.
