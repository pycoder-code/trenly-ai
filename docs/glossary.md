# Глоссарий

Единый словарь терминов для документации, спецификаций и кода. Колонка «В коде» фиксирует англоязычное имя, чтобы оно совпадало в документации, бэкенде и фронтенде.

| Термин | В коде | Определение |
|---|---|---|
| Тренер | `Trainer` | Персональный фитнес-тренер; работает в веб-кабинете. На текущем роадмапе учётку заводит администратор. |
| Клиент | `Client` | Подопечный тренера; бесплатно работает в боте и в Mini App. Подключён ровно к одному тренеру. |
| Администратор | `Admin` | Сотрудник Trenly; управляет тренерами в админке. |
| Админка | `AdminPanel` | Интерфейс администратора на Django Admin. |
| Подписка | `Subscription` | Ежемесячная оплата тренером доступа к Trenly. Без активной подписки клиенты тренера могут только просматривать свои статусы и графики. |
| Пробный период | `Trial` | Бесплатный период после регистрации тренера со всеми функциями. |
| Кабинет тренера | `TrainerDashboard` | Веб-приложение тренера в браузере. |
| Mini App | `ClientMiniApp` | Веб-приложение клиента внутри Telegram: дневник и итог КБЖУ за день, ручной ввод КБЖУ на приём пищи, тренировки по дням, статистика посещённых тренировок. |
| Бот | `TelegramBot` | Telegram-бот Trenly: чат клиента. Подключение, анкета, фото еды, согласие на занятие за день до него. |
| Подключение | `ClientInvite` | Ссылка, которой тренер открывает клиенту бота. |
| Анкета | `Questionnaire` | Данные, которые клиент называет в диалоге бота: имя, фамилия, дата рождения, рост, вес, цель. В конце он подтверждает привязку к тренеру по ссылке. |
| Цель | `Goal` | Чего добивается клиент: похудение, набор мышечной массы и т. п. |
| Дневник питания | `NutritionDiary` | Записи о приёмах пищи клиента с КБЖУ. |
| КБЖУ | `Macros` | Калории, белки, жиры, углеводы. |
| Рекомендация | `NutritionRecommendation` | Ежедневный совет клиенту по питанию с учётом цели. |
| Тренировка | `Workout` | Занятие, которое тренер записывает клиенту. |
| Отметка посещения | `Attendance` | Ответ клиента за день до занятия, которое записал тренер: придёт или нет. |
| Награда | `Reward` | Достижение клиента за регулярность. |
| Журнал | `Journal` | Автоматическая хронология питания, тренировок и посещений клиента. |
| Отчёт | `ProgressReport` | Сводка прогресса клиента за период. |
