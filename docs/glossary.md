# Глоссарий

Единый словарь терминов для документации, спецификаций и кода. Колонка «В коде» фиксирует англоязычное имя, чтобы оно совпадало в документации, бэкенде и фронтенде.

| Термин | В коде | Определение |
|---|---|---|
| Тренер | `Trainer` | Персональный фитнес-тренер; платит за подписку и работает в веб-кабинете. |
| Клиент | `Client` | Подопечный тренера; работает через Telegram-бота бесплатно. Подключён ровно к одному тренеру. |
| Подписка | `Subscription` | Ежемесячная оплата тренером доступа к Trenly. Без активной подписки клиенты тренера могут только просматривать свои статусы и графики. |
| Пробный период | `Trial` | Бесплатный период после регистрации тренера со всеми функциями. |
| Кабинет тренера | `TrainerDashboard` | Веб-приложение тренера. |
| Бот | `TelegramBot` | Telegram-бот Trenly — единственный канал клиента. |
| Подключение | `ClientInvite` | Выдача тренером клиенту доступа к боту (ссылка или QR-код). |
| Анкета | `Questionnaire` | Исходные данные клиента: параметры, ограничения, цель. |
| Цель | `Goal` | Чего добивается клиент: похудение, набор мышечной массы и т. п. |
| Дневник питания | `NutritionDiary` | Записи о приёмах пищи клиента с КБЖУ. |
| КБЖУ | `Macros` | Калории, белки, жиры, углеводы. |
| Рекомендация | `NutritionRecommendation` | Ежедневный совет клиенту по питанию с учётом цели. |
| Тренировка | `Workout` | Занятие клиента с тренером или самостоятельное. |
| Отметка посещения | `Attendance` | Подтверждение или отмена клиентом предстоящей тренировки. |
| Награда | `Reward` | Достижение клиента за регулярность. |
| Журнал | `Journal` | Автоматическая хронология питания, тренировок и посещений клиента. |
| Отчёт | `ProgressReport` | Сводка прогресса клиента за период. |
