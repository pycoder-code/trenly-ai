# Продуктовые метрики

Метрики показывают, достигаются ли [цели продукта](vision.md#цели). Целевые значения задаются после запуска, по первым данным.

## Бизнес

| Метрика | Определение | Цель |
|---|---|---|
| Платящие тренеры | Число тренеров с активной подпиской | G5 |
| Конверсия пробного периода | Доля тренеров, оплативших подписку после пробного периода | G5 |
| Отток тренеров | Доля тренеров, не продливших подписку за месяц | G1, G5 |
| MRR | Ежемесячная выручка от подписок | G5 |

## Тренер

| Метрика | Определение | Цель |
|---|---|---|
| Клиентов на тренера | Среднее число активных клиентов у платящего тренера | G1 |
| Активация тренера | Доля новых тренеров, подключивших хотя бы 3 клиентов за пробный период | G1, G5 |
| Активность в кабинете | Доля тренеров, заходивших в кабинет за последнюю неделю | G1, G4 |

## Клиент

| Метрика | Определение | Цель |
|---|---|---|
| Завершение анкеты | Доля подключённых клиентов, заполнивших анкету | G3 |
| Регулярность дневника | Доля клиентов, внёсших питание не менее 5 дней из 7 | G2, G3 |
| Удержание клиента | Доля клиентов, активных в боте через 30 дней после подключения | G2 |
| Подтверждение посещений | Доля тренировок, по которым клиент заранее ответил «приду / не приду» | G2 |

## Качество

| Метрика | Определение | Цель |
|---|---|---|
| Точность КБЖУ по фото | Доля оценок, которые клиент не исправил вручную | G3, G4 |
