# Персональные данные

Пользователи Trenly находятся в России, обработка данных подчиняется 152-ФЗ. Trenly обрабатывает персональные данные, в том числе сведения о здоровье и физических параметрах клиентов (вес, замеры, фото, травмы). Требования к ним строже, чем к обычным персональным данным.

## Категории данных

| Данные | Категория | Где хранятся | Срок хранения |
|---|---|---|---|
| Имя, Telegram-аккаунт, контакты | Персональные | БД, РФ | |
| Анкета: параметры тела, ограничения по здоровью, цель | Сведения о здоровье (уточнить с юристом) | БД, РФ | |
| Фото еды | Персональные (привязаны к клиенту) | Yandex Object Storage, РФ ([ADR 0002](../architecture/adr/0002-photo-storage.md)) | 90 дней |
| Дневник питания, тренировки, посещения | Персональные | БД, РФ | |

## Требования

| ID | Требование |
|---|---|
| NFR-PRIV-002 | Пользователь может удалить аккаунт и свои данные |
| NFR-PRIV-003 | Персональные данные хранятся на серверах в РФ |
| NFR-PRIV-004 | Передача фото и данных клиентов внешним сервисам за пределами РФ (например, AI-моделям) допускается только после согласования с юристом |
