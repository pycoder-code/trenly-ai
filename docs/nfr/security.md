# Безопасность

## Аутентификация и авторизация

Администратор входит в Django Admin учётной записью Django `User` со `is_staff`.

Тренер этой учётной записью не является и в админку не входит. В кабинет он входит телефоном и паролем:
`POST /api/access-tokens` выдаёт токен доступа и токен обновления. `POST /api/refresh-tokens` выдаёт новую пару.
Следующие запросы кабинета передают токен доступа
в заголовке `Authorization: Bearer`. Заблокированный тренер войти не может, а уже выданный токен доступа отклоняется со
следующего запроса. Сроки и форма токенов — в [ADR 0010](../architecture/adr/0010-trainer-cabinet-jwt.md). Учётка
тренера — в [ADR 0007](../architecture/adr/0007-trainer-is-not-django-user.md).

## Модель доступа

| Действие                     | Тренер                | Клиент      |
| ---------------------------- | --------------------- | ----------- |
| Видит данные клиента         | Только своих клиентов | Только свои |
| Отправляет сообщения клиенту | Да                    | Нет         |
