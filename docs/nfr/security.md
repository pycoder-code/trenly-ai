# Безопасность

## Аутентификация и авторизация

Администратор входит в Django Admin учётной записью Django `User` со `is_staff`.

Тренер этой учётной записью не является и в админку не входит. В кабинет он входит телефоном и паролем: `POST /api/trainer-sessions` выдаёт Bearer-токен на 14 дней. Следующие запросы кабинета передают заголовок `Authorization: Bearer`. Заблокированный тренер войти не может, а уже выданный токен отклоняется со следующего запроса. Подробности — в [ADR 0007](../architecture/adr/0007-trainer-is-not-django-user.md).

## Модель доступа

| Действие | Тренер | Клиент |
|---|---|---|
| Видит данные клиента | Только своих клиентов | Только свои |
| Отправляет сообщения клиенту | Да | Нет |
