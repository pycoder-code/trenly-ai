# C4-модель

Архитектура Trenly описана по модели [C4](https://c4model.com): четыре уровня, от общего к частному. Каждый уровень — отдельный файл с описанием элементов и диаграммой на Mermaid (отображается в Cursor и Git без дополнительных инструментов).

| Уровень | Файл | Что показывает | Статус |
|---|---|---|---|
| 1. Контекст | [context.md](context.md) | Trenly как единое целое: пользователи и внешние системы | Черновик |
| 2. Контейнеры | [containers.md](containers.md) | Из каких приложений и хранилищ состоит Trenly | Черновик |
| 3. Компоненты | [components.md](components.md) | Из каких модулей состоит каждый контейнер | Не начато |
| 4. Код | [code.md](code.md) | Классы и структуры ключевых компонентов | Не начато |

## Правила

- Имена элементов одинаковы на всех уровнях, и в [глоссарии](../../glossary.md).
- Значимое изменение архитектуры сопровождается [ADR](../adr/README.md).
- Логическая схема базы ведётся отдельно в [модели данных](../data-model.md). Изменение постоянных моделей, полей или связей обновляет этот файл в том же изменении.
- Если элемент появится только на определённом этапе, это указывается в описании (например, «с E10»).
