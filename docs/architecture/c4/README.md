# C4-модель

Архитектура Trenly описана по модели [C4](https://c4model.com): четыре уровня, от общего к частному. Каждый уровень —
отдельный файл с описанием элементов и диаграммой на Mermaid (отображается в Cursor и Git без дополнительных
инструментов).

- **Уровень:** 1. Контекст. **Файл:** [context.md](context.md). **Что показывает:** Trenly как единое целое:
  пользователи и внешние системы. **Статус:** Черновик
- **Уровень:** 2. Контейнеры. **Файл:** [containers.md](containers.md). **Что показывает:** Из каких приложений и
  хранилищ состоит Trenly. **Статус:** Черновик
- **Уровень:** 3. Компоненты. **Файл:** [components.md](components.md). **Что показывает:** Из каких модулей состоит
  каждый контейнер. **Статус:** Черновик
- **Уровень:** 4. Код. **Файл:** [code.md](code.md). **Что показывает:** Классы и структуры ключевых компонентов.
  **Статус:** Черновик

## Правила

- Имена элементов одинаковы на всех уровнях, и в [глоссарии](../../glossary.md).
- Значимое изменение архитектуры сопровождается [ADR](../adr/README.md).
- Логическая схема базы ведётся отдельно в [модели данных](../data-model.md). Изменение постоянных моделей, полей или
  связей обновляет этот файл в том же изменении.
- Если элемент появится только на определённом этапе, это указывается в описании (например, «с E3»).
