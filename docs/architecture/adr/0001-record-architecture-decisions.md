# 0001. Фиксировать архитектурные решения в ADR

- **Статус:** Принято
- **Дата:** 2026-11-09

## Контекст

Архитектурные решения принимаются в обсуждениях и со временем теряются. Новым участникам и ИИ-агентам нужно понимать, почему система устроена именно так.

## Решение

Каждое значимое архитектурное решение записываем в ADR по [шаблону](../../../templates/adr.md). Файлы нумеруются последовательно: `NNNN-короткое-название.md`. Принятый ADR не редактируется; чтобы изменить решение, создаётся новый ADR со ссылкой на заменяемый.

## Последствия

- История решений хранится рядом с C4-моделью.
- Изменение архитектуры требует написать ADR.
