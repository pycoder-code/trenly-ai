# 0010. Токен кабинета тренера — JWT

- **Статус:** Принято
- **Дата:** 2026-11-17
- **Уточнено:** 2026-11-17
- **Дополняет:** [ADR 0007](0007-trainer-is-not-django-user.md)

## Контекст

Тренер входит в личный кабинет телефоном и паролем и не является учётной записью Django
([ADR 0007](0007-trainer-is-not-django-user.md)). `POST /api/trainer-sessions` уже выдаёт токен, но это подписанная
Django-строка на 14 дней, не пара access и refresh. Кабинет на сайте ещё не собран, поэтому формат токена можно сменить
до экрана входа.

Токен клиента Mini App и сервисный токен бота этим решением не задаются.

## Рассмотренные варианты

1. **Оставить подписанную Django-строку на 14 дней.** Проверка уже написана. Один долгоживущий секрет и есть токен
   доступа.
2. **Сессия cookie.** Браузер хранит сессию сам. Отдельное SPA стыкуется с ней хуже, чем с токеном в заголовке.
3. **Один JWT на 14 дней.** Формат стандартный, но украденный токен доступа живёт две недели.
4. **Короткий access JWT и отдельный refresh.** Телефон и пароль остаются способом входа. Запросы кабинета несут
   короткий JWT. Новый access получают refresh-токеном, без повторного пароля.

## Решение

Принимается вариант 4.

Тип авторизации тренера в личном кабинете — JWT для токена доступа. Тренер по-прежнему входит телефоном и паролем.

- Токен доступа — JWT на 15 минут. Запросы кабинета передают его в `Authorization: Bearer`.
- Токен обновления живёт 14 дней. Им получают новую пару. Сам по себе кабинет он не открывает. После выдачи новой пары
  прежний токен обновления не действует.
- Заблокированный тренер пару не получает. Уже выданный токен доступа отклоняется со следующего запроса, токен
  обновления перестаёт выдавать новую пару.

## Последствия

- Текущая подписанная Django-строка в `POST /api/trainer-sessions` заменяется на эту пару в эпике E2.1.
- Смена `SECRET_KEY` завершает выданные JWT доступа. Токены обновления хранятся на сервере и отзываются отдельно.
- Токен клиента Mini App и сервисный токен бота остаются отдельными и этим решением не становятся JWT.
