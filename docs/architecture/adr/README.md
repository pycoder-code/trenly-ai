# Архитектурные решения (ADR)

Каждое решение — отдельный файл `NNNN-название.md` по [шаблону](../../../templates/adr.md). Поле «Нужно к» показывает
эпик [роадмапа](../../business/roadmap.md), до начала которого решение должно быть принято.

- **ADR:** [0001](0001-record-architecture-decisions.md). **Решение:** Фиксировать архитектурные решения в ADR.
  **Нужно к:** E1. **Статус:** Принято
- **ADR:** [0002](0002-photo-storage.md). **Решение:** Хранение фото еды в Yandex Object Storage. **Нужно к:** E3.
  **Статус:** Принято
- **ADR:** [0003](0003-monorepo.md). **Решение:** Монорепозиторий. **Нужно к:** E1. **Статус:** Принято
- **ADR:** [0004](0004-macros-recognition-openrouter.md). **Решение:** Распознавание КБЖУ через OpenRouter (Gemini 3.8
  Flash). **Нужно к:** E3. **Статус:** Предложено
- **ADR:** [0005](0005-tech-stack.md). **Решение:** Стек: Django + DRF, PostgreSQL, Django Admin, Vue 3. **Нужно к:**
  E1. **Статус:** Принято
- **ADR:** [0006](0006-telegram-bot-aiogram.md). **Решение:** Telegram-бот: aiogram 3 и `aiogram_dialog` 2 в `tg_bot/`,
  связь с Django по HTTP. **Нужно к:** E1. **Статус:** Принято
- **ADR:** [0008](0008-client-mini-app.md). **Решение:** Mini App клиента и кабинет тренера в браузере. **Нужно к:** E1.
  **Статус:** Принято
- **ADR:** [0009](0009-ui-design-figma.md). **Решение:** Разработка UI-дизайна в Figma AI. **Нужно к:** E1. **Статус:**
  Принято
- **ADR:** [0007](0007-trainer-is-not-django-user.md). **Решение:** Тренер не является учётной записью Django.
  **Нужно к:** E2. **Статус:** Принято
- **ADR:** —. **Решение:** Хостинг и деплой. **Нужно к:** E1. **Статус:** Предстоит
- **ADR:** —. **Решение:** Фоновые задачи (напоминание за день до занятия). **Нужно к:** E3. **Статус:** Предстоит
- **ADR:** —. **Решение:** Платёжный провайдер. **Нужно к:** —. **Статус:** Предстоит

Эпик стартует после того, как приняты решения с его номером в поле «Нужно к». Платёжный провайдер относится к
[BR-007](../../business/requirements.md#br-007-регистрация-тренера-и-подписка) и в текущий роадмап не входит.
