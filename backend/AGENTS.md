# Backend

Django-приложение — домен (`trainers`, `clients`). Новый домен появляется вместе с термином в глоссарии. Слои —
[ADR 0011](../docs/architecture/adr/0011-domain-layers.md).

## Имена

- Модуль слоя называется `{имя}_{слой}`, класс — `{Имя}{Слой}`: `client_entity.ClientEntity`,
  `client_repository.ClientRepository`.
- Сценарий с представлением носит одно имя. `ClientListView` → `ClientListDto` → `ClientListService` →
  `ClientListResponseSerializer`. Тело запроса — `{Имя}RequestSerializer`.
- Сериализатор запроса — модуль `{имя}_request_serializer`, класс `{Имя}RequestSerializer`:
  `trainer_auth_request_serializer.TrainerAuthRequestSerializer`.
- Общий ответ двух сценариев описывает один сериализатор.
- Класс модели называется как сущность. Импорт — `from clients.models import Client`.

## Слои

### api

Принимает HTTP и описывает OpenAPI. Представление собирает DTO в переменную `params`, вызывает только `run` и выбирает
код ответа. Сериализатор запроса проверяет и приводит поля тела. Представление берёт их из `validated_data`.

### services

Выполняет сценарий. Класс с методом `run(self, params)`: на вход DTO, на выход сущность. Не возвращает `Response` и DTO,
не собирает `QuerySet` и не вызывает другой сервис.

### entities

Держит сущность и правило одной записи.

### repositories

Переводит модель в сущность и обратно. Наружу не отдаёт `QuerySet`. Перевод строки — метод `_to_entity`.

### models

Хранит таблицы. Это пакет: каждая модель — отдельный модуль. У класса нет методов с правилами. Нормализация и проверка
живут в `entities`. Изменение модели, поля или связи в том же изменении обновляет `docs/architecture/data-model.md`.

## REST

Пути — по
[руководству Microsoft](https://learn.microsoft.com/ru-ru/azure/architecture/best-practices/api-design).

- URI называет ресурс существительным. Действие задаёт метод HTTP: `GET`, `POST`, `PUT`, `PATCH`, `DELETE`.
- Коллекция — существительное во множественном числе: `GET /api/clients`. Элемент коллекции — `/api/clients/{id}`.
- `POST` в коллекцию создаёт ресурс. URI назначает сервер, успешный ответ — `201`. Пример: `POST /api/access-tokens`,
  `POST /api/refresh-tokens`.
- Связь ресурсов не глубже коллекции, элемента и вложенной коллекции.
- Путь не повторяет таблицы базы. Имя ресурса берётся из глоссария, поле «В коде».

## Docstring

У модуля, класса и функции есть docstring. Он короткий и понятный, на русском языке.

## Границы

- `config/urls.py` только подключает `<домен>.api.urls`.
- Представление не обращается к модели и не решает правило сценария.
- Сервис не импортирует `api`.
- Репозиторий не проверяет пароль и не выбирает код ответа.
- Новый сценарий добавляется сервисом и DTO, а не методом представления.
- Раскладка пакетов не меняет путь API. Ломающее изменение контракта сначала фиксируется в спецификации и в снимке
  OpenAPI.
