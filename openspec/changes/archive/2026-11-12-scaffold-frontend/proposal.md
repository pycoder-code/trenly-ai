# Proposal

## Why

Каталога `frontend/` нет, хотя ADR о Mini App уже задаёт отдельное приложение клиента. Оболочку и общий клиент API нужно собрать до экранов анкеты и дневника. Кабинет тренера в это изменение не входит.

## What Changes

- Появляется `frontend/`: pnpm workspace с пакетами `miniapp/` и `api-client/`. Общий клиент API генерируется из схемы Django и пока никем не вызывается.
- Mini App (`miniapp/`) только собирается и открывается на теме Telegram. Экранов анкеты, дневника, истории, наград и отчёта нет: входа клиента ещё нет.
- Пакет `dashboard/`, форма входа и список клиентов не создаются.
- Графики, CORS, деплой и вызов Django из Mini App не входят.

## Capabilities

### New Capabilities

Нет. Экранов, которые видит тренер или клиент, это изменение не добавляет.

### Modified Capabilities

Нет. В `openspec/specs/` требований ещё нет.

## Impact

- `frontend/` — новый каталог: оболочка Mini App и генерация клиента из OpenAPI.
- `docs/` — дерево репозитория в README. Номер ADR про Mini App совпадает с ADR «тренер не является учётной записью Django»; Mini App становится ADR 0008.
- `backend/` и `tg_bot/` не меняются. Новых путей API нет.
