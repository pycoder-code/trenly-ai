# Design

## Context

См. [proposal.md](proposal.md). Контракт уже в снимке `frontend/api-client`: `POST /api/access-tokens`,
`POST /api/refresh-tokens`, `GET /api/trainers/me`, `GET /api/clients`. Отказ входа и кабинета — `401` и
`{"detail": "Неверные учётные данные."}`. Схема OpenAPI этот отказ не описывает. `createApiClient` принимает только
`baseUrl` и заголовок Bearer не ставит. CORS в Django нет. Фото тренера локально отдаётся с `/media/trainer-photos/`,
адрес в ответе абсолютный от хоста запроса.

Внешний вид — кадры `index_page`, `dashboard_page` и `clients_page` в
[Trenly — кабинет тренера](https://www.figma.com/design/ACCi8fiNVogHW2gaqmrqG8). Из `dashboard_page` берутся пустой день
«Сегодня», меню кабинета и окно приглашения: в поле фейковая ссылка на бота, в пояснении — «Рыбой». Строка клиента на
кадре — фамилия и имя, без телефона, роста и веса.

## Goals / Non-Goals

**Goals:**

- Собрать кабинет, который ходит в уже готовый API и повторяет главную, вход, пустой дашборд и список.
- Хранить сессию так, как уже записано для кабинета: токен доступа в памяти, токен обновления в `localStorage`.

**Non-Goals:**

- Новый путь API, поле ошибки в OpenAPI, CORS и правка `backend/`.
- Создание клиента и реальные занятия на сегодня. Окно приглашения входит в изменение и показывает текст «Рыбой».
- Показ телефона, роста, веса и признака активности в строке списка.

## Decisions

### Backend

Не меняется. Отказ формы читается из поля `detail` ответа `401`. Если поля нет, форма показывает одну общую фразу отказа
и не открывает список.

### Frontend

1. **Пакет `frontend/dashboard/`.** Vue 3, TypeScript, Vite, vue-router, PrimeVue, Pinia. Каталог добавляется в
   `frontend/pnpm-workspace.yaml`. Mini App и `@tma.js` пакет не импортирует. Общего каталога компонентов нет.
2. **Три маршрута.** `/` — `HomeView`, открыт без сессии. `/dashboard` — `DashboardView`, пустой день «Сегодня».
   `/clients` — `ClientListView`. `beforeEach` пускает на дашборд и список только после токена доступа. Без него
   остаётся главная.
3. **Форма входа — окно на главной**, не отдельный маршрут. Поля — телефон и пароль. Закрытие окна не вызывает API.
   Успех `201` кладёт пару токенов и переходит на `/dashboard`. `401` оставляет окно.
4. **`useAuthStore`.** Токен доступа в памяти, токен обновления в `localStorage`. «Выйти» стирает оба и открывает `/`.
   До первого перехода действующий токен обновления меняется на новую пару через `POST /api/refresh-tokens`. Повторный
   вызов, пока обмен не закончился, ждёт тот же запрос. Неудача обмена стирает сессию. Токен обновления сам маршруты
   `/dashboard` и `/clients` не открывает: сначала нужна новая пара.
5. **Bearer ставит `api-client`.** `createApiClient` получает необязательную функцию текущего токена доступа. Без неё
   заголовок не добавляется, Mini App не ломается. Экран заголовок не собирает. Повтор запроса после `401` на
   `/api/trainers/me` и `/api/clients` делает стор один раз: новая пара и тот же запрос. Вход по `401` пару не
   обновляет.
6. **Один origin через прокси Vite.** Запросы идут на тот же origin, что и кабинет: `/api` и `/media` проксируются на
   Django. Так фото с хоста запроса открывается без CORS. Базовый URL клиента — пустой origin кабинета.
7. **Шапка.** `GET /api/trainers/me`. Подпись «Тренер» постоянная. Инициалы — первые буквы имени и фамилии. Нет фамилии
   — первая буква имени. Фото, если `photo` не `null`, заменяет инициалы.
8. **Список.** `GET /api/clients` живёт в `ClientListView`. Поиск и порядок считаются на уже загруженном массиве, нового
   параметра API нет. Сравнение имён — русская локаль, сначала фамилия, без фамилии — имя. Фрагмент поиска ищется без
   учёта регистра в фамилии и имени. Число на экране — сколько строк показано. Пустой ответ API показывает «Клиентов
   пока нет» и не показывает строку про приглашение.

### tg_bot

Не меняется.

## Risks / Trade-offs

- [Окно приглашения есть, а API ссылки нет] → В поле стоит фейковая ссылка `https://t.me/trenly_bot?start=7K4M9P`, в
  пояснении — «Рыбой». «Скопировать» меняет кнопку на «Скопировано» и не создаёт клиента. Пустой список по-прежнему
  пишет только «Клиентов пока нет».
- [Отказ `401` не описан в OpenAPI] → Текст берётся из `detail`, контракт не расширяется. Смена фразы на бэкенде изменит
  текст формы без правки типов.
- [Прокси Vite есть только локально] → Для выкладки origin кабинета и API ещё не выбран. Это не блокер эпика: локально
  кабинет и Django на разных портах.

## Migration Plan

Локальный пакет. Откат — не подключать `dashboard/` к workspace. Данных и миграций нет.
