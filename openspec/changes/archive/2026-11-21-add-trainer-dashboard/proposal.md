# Proposal

## Why

API кабинета уже пускает тренера и отдаёт его имя и своих клиентов, но сайта нет: пакет `frontend/dashboard/` не создан.
Эпик E2.2 как раз про вход на сайт и список своих клиентов. Макеты главной, входа и списка уже лежат в Figma, код от них
отстаёт.

## What Changes

- Появляется пакет `frontend/dashboard/`: главная, вход телефоном и паролем и список своих клиентов по кадрам
  `index_page` и `clients_page` файла [Trenly — кабинет тренера](https://www.figma.com/design/ACCi8fiNVogHW2gaqmrqG8).
- На главной кнопка «Войти» открывает форму: телефон, пароль и отправка. Успешный вход открывает пустой дашборд
  «Сегодня». Отказ оставляет тренера на форме.
- В шапке списка — имя и фамилия вошедшего тренера, подпись «Тренер», инициалы или фото и «Выйти». «Выйти» стирает пару
  токенов и возвращает на главную.
- Список показывает имя клиента: фамилия и имя, а если фамилии нет — только имя. Поиск сужает уже загруженный список,
  порядок — по алфавиту. Пустой список показывает, что клиентов нет.
- После входа тренер видит пустой дашборд «Сегодня» по кадру «Занятий нет». Список клиентов открывается из меню
  кабинета: на широком экране пункты в шапке, на узком — по кнопке меню. Со списка есть «← На дашборд». Пункт
  «Пригласить нового клиента» открывает окно по мобильным кадрам «Пригласить клиента» и «Ссылка скопирована». Пояснение
  — «Рыбой», в поле — фейковая ссылка на бота. Клиента окно не создаёт. Занятия на сегодня остаются в E3.
- Контракт API не меняется. `POST /api/access-tokens`, `POST /api/refresh-tokens`, `GET /api/trainers/me` и
  `GET /api/clients` остаются как есть. Телефон, рост, вес и признак активности клиент API по-прежнему отдаёт; на кадре
  списка их нет, экран их не рисует.

## Capabilities

### New Capabilities

Нет.

### Modified Capabilities

- `trainer-dashboard`: тренер открывает сайт, входит и видит список своих клиентов.

## Impact

- `frontend/dashboard/` — новое приложение Vue 3, PrimeVue и Pinia. `frontend/api-client/` подставляет
  `Authorization: Bearer`. Снимок OpenAPI не меняется.
- `backend/`, `tg_bot/` и `docs/` не меняются. Новый ADR не нужен: контейнер кабинета уже описан.
- Макет не переносится в репозиторий. Источник внешнего вида — файл Figma выше.
